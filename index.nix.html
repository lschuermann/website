    Hi, I'm Leon!

    PhD candidate in Computer Science at Princeton University

    I study how we can use operating systems and programming languages to make software safer, more secure, and more reliable.

    My work includes projects to facilitate safe interactions between Rust, foreign languages, and concurrent hardware. I am a core maintainer of the Tock operating system, which is used as a root of trust on tens of millions of devices.

    I am advised by Amit Levy in the SNS Research Group and collaborate closely with Mae Milano.

    Project highlights

    Omniglot

    Using foreign libraries shouldn’t mean giving up Rust’s safety guarantees. Omniglot combines memory isolation, type validation, and static checks to preserve those guarantees—even with unmodified, untrusted libraries, and without copying shared data. We demonstrate it in Linux applications and the Tock kernel.

    OSDI ’25 · Best Paper Award

    Read the OSDI'25 paper → Read the ;login: introduction →

    Tock

    I am a core maintainer of Tock, a secure operating system for embedded devices. My contributions span the kernel’s application-memory interfaces, RISC-V memory protection, and sound abstractions for DMA—helping preserve Rust’s safety guarantees across interactions with untrusted applications and hardware.

    SOSP ’25 · From research to deployed systems

    Explore Tock → Read our SOSP'25 retrospective →

    Treadmill Distributed Hardware Testbed

    Embedded software is difficult to test automatically, especially across chips and boards developers don’t have locally. I’m building Treadmill to make automated testing on real hardware accessible, with remote access for interactive development and debugging.
